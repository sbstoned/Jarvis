MIXED TOOLCHAIN BEHAVIOR
------------------------
A synthetic Node + Rust repository was detected as two independent components. The sandbox has npm but not Cargo; V35 validated the Node component and then correctly failed/unverified the Rust component instead of returning early after Node. This demonstrates the V34.1 single-toolchain early-return problem is removed.

RELEASE POLICY
--------------
V35 only marks a generated project COMPLETED when every required discovered component can pass its applicable dependency/build/test/runtime/acceptance gates on the generation host. Missing host-specific toolchains are reported as UNVERIFIED_HOST_TOOLCHAIN rather than false success.
